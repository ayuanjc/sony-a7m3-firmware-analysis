# 关于 SONY A7M3 最新版本固件分析

对 Sony Alpha 7 III（ILCE-7M3）系统软件更新包 **Update_ILCE7M3V404.exe** 的静态格式分析。

本仓库只描述**封装格式**与**容器结构**，不含任何解密密钥、破解工具，也不含可直接刷写的固件镜像。

> 结论先行：三层封装已完整还原（Packman 自解压 → MSCF cab → UFU 容器）；
> 固件本体（FDAT 段）为分组密码密文，密钥位于相机端，PC 侧不存在任何解密实现。

## 分析对象

| 项 | 值 |
|---|---|
| 文件名 | Update_ILCE7M3V404.exe |
| 大小 | 339,275,208 字节 |
| SHA-256 | `8c356688a70946a855191e99fd4d9096a5c3d4263f3f11065605eaea45639d57` |
| 格式 | PE32 / i386 / 5 sections / ImageBase 0x400000 |
| 打包器 | Sony Sony Packaging Tool (Packman) 自解压器 |
| 内部更新器 | FirmwareUpdaterEg.exe 3.2.00.06230（MFC，2010-2021） |

## 快速结论

1. exe 尾部 overlay 是一张 **Packman 条目表**：UTF-16LE 明文文件名 + FILETIME + 尺寸 + 文件内偏移。
2. 内嵌 cab 以**逐字节按位取反（XOR 0xFF）**存放，还原后是标准 **MSCF** cab
   （LZX:21，10 blocks，45 文件，344,321,724 字节）。
3. cab 内 `FirmwareData_ILCE7M3V404.dat` 是 **UFU** 容器：
   8 字节魔数 + TLV 链 `DATV` / `PROV` / `UDID` / `FDAT` / `DEND`。
4. `DEND` 是标准 **CRC-32**（IEEE，大端），覆盖魔数到 `FDAT` 载荷末尾，实测一致。
5. `FDAT`（335,395,088 字节，16 字节对齐）为分组密码密文；更新器**只记录偏移与长度后 Seek 跳过**，
   PC 侧不含任何解密或校验实现。

细节见 [ANALYSIS.md](ANALYSIS.md)。

## 复现

需要 Python 3.9+；7-Zip 可选（仅用于展开内层 cab）。

    python tools/sony_fw_unpack.py /path/to/Update_ILCE7M3V404.exe

脚本依次完成：定位 Packman 表 → 提取并还原 cab → 展开 → 解析 UFU TLV 链 →
校验 DEND CRC-32 → 列出 UDID 白名单 → 统计 FDAT 块结构。
**脚本不执行任何解密**，也不会接触相机设备。
